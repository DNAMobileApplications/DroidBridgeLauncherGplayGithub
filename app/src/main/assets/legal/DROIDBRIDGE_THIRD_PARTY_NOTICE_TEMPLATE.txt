DroidBridge Third-Party Notices Template

Before publishing on Google Play, replace this template with the complete notices for the exact binaries and source components included in your release APK/AAB.

Expected notice categories:

- LWJGL / GLFW bridge components
- OpenJDK / Android runtime components included with DroidBridge
- Mesa / Turnip / Zink / renderer-related native components bundled with the APK
- SDL Java wrapper and native components, where included
- AndroidX, Material Components, AppAuth, OkHttp, Gson, Apache Commons Compress, XZ for Java, ByteHook, Play Integrity, and other Gradle dependencies
- Any renderer/plugin interfaces or optional compatibility code whose license requires attribution
- Any Fabric/loader/mod tooling distributed directly with the launcher

Do not use this template as final legal compliance. It is a reminder file so the APK tree has a clear location for production notices.
